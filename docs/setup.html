dockeriser setup

About 5 minutes, once. After this, Docker builds run on Google instead of your PC.

  1. Install Google's command-line tool

    winget install Google.CloudSDK

    Then open a new terminal so it's found.

  2. Run the setup script

    From the dockeriser folder. It asks which project to use (or pass -Project my-id), and opens your browser to sign in to Google.

    powershell -ExecutionPolicy Bypass -File setup\setup.ps1

    Or from anywhere:

    powershell -ExecutionPolicy Bypass -File "C:\Users\camer\Desktop\Projects\dockeriser\setup\setup.ps1"

    It sets up the project, billing, a $5 budget alert and everything else, then checks it all. Safe to run again. Near the end it may show “waiting for Google to apply the new permissions…” for up to about 3 minutes; that is normal.

    In Claude Code, /dockeriser:setup does this step: it asks in chat which project to use, then runs the script.

  3. Try a build

    node bin\dockeriser.js build examples\hello --image hello

    You should see the build log stream in, then the image address with its digest and a line like Cloud Build: 0.2 / 2,500 free min this month (0%). The first real build took 11 seconds, about 0.2 minutes. In Claude Code: /dockeriser:build examples\hello hello.

Check usage any time with node bin\dockeriser.js usage, or /dockeriser:usage in Claude Code. If something fails, run the setup script again; it tells you what's missing.
